Total columns: 29 → 28. `calculatePaySlipBreakdown` defaults: `shift_hours` defaults from `rateRow.shift_allowance_hours_per_week` (per-payslip input still wins when supplied); new default `personal_leave_hours: 0`. New derived output `personal_leave`. `calculateHolidayLeaveAccrual` and the leave-balance tracking (Amendment 5) unchanged.
