## Conventions

- ADRs are numbered sequentially (`NNNN-short-name.md`).
- Status values: `Proposed`, `Accepted`, `Deprecated`, `Superseded by NNNN`.
- Each ADR ends with a "Revisit triggers" section so future agents know when to reconsider.
