Pay Rate History

Effective-dated rate rows · used by PayService.calculatePaySlipBreakdown via PayRateService.getRateForDate(pay_date)

One rate row has effective_to = NULL at any time — that's the current rate. Adding a new rate row automatically closes the previous current row (sets its effective_to to the new row's effective_from). Historical payslips always compute with their era's rates, so a back-dated payslip import always uses the right values.
