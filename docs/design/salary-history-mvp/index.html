corepayslip-form · collapsed
Default state. Only Period + Earnings preview + Deductions + Super + Notes visible. The "This week was different" toggle is off; hours default from settings.
corepayslip-form · expanded
User toggled "This week was different" on. Six hour fields visible (regular, shift, OT 1.5x, OT 2.0x, holiday, public holiday). Personal leave + accrual also shown.
warningpayslip-form · reconciled
Same expanded form, but the sum of derived earnings ≠ entered gross. Shows the inline reconciliation warning + the Validate PAYG button + its result.
listpayslip-list
Paginated table of payslips (pay_date, finance_year, gross, net, account) with Edit/Delete actions per row. YTD summary footer at the bottom.
newpay-rate-history
Rate history list view. Shows effective_from, effective_to, all 7 rate columns, notes. "Current" badge on the active row. [Add New Rate] opens rate-row-form.
newrate-row-form
Add/edit a rate row. Form fields: effective_from, effective_to, 7 rate columns, notes. Validates via PayRateService.validateRateRow.
newreorder-sections
Modal with up/down arrows for the 6 form section IDs. Saves to salary-history.sectionOrder settings key.
setupaccounts-seed
First-run prompt when accounts table is empty. User can create an account (name, institution) or skip (Phase 5's Accounts extension handles later).
