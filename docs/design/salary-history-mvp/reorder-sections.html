How this is stored: clicking Save writes the array to salary-history.sectionOrder in the settings table (Phase 2 SettingsService). On the next payslip form render, sections are read in this order. First row gets a green left border; last row gets a purple left border. Disabled arrows indicate the section can't move further in that direction.
Default order: period, totals, earnings, deductions, super, leave, leave-accrual, notes
