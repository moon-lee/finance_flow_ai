Phase 5 — Webviews & Multi-Extension UI Mockups

HTML design previews for Phase 5's new surfaces: Dashboard, tab bar, split-pane, and navigation panel. Open any mock below to inspect the design before implementation.

Plan docs/superpowers/plans/2026-07-18-phase5-webviews-multiextension.md
Scope Dashboard 4-card layout, tab bar, 2-pane split, navigation panel
Styling Inline CSS, Obsidian dark theme, self-contained HTML files (same convention as Phase 4 mocks)
newDashboard — 4-card layout
Default startup view. Net Worth, YTD Salary, Last Payslip, Accounts Summary cards in a 2×2 grid. Navigation panel on the left. Tab bar at the top.
coreTab bar — multi-tab workspace
Two open tabs (Dashboard active, Salary History background). Close buttons, active tab highlight, overflow affordance when more tabs exist.
newSplit-pane — 2-pane layout
Dashboard on the left, Salary History on the right. Draggable horizontal splitter. Closing the last tab in a pane collapses the split.
coreNavigation panel — data-driven sidebar
Activity Bar icons on the far left. Navigation items rendered from the active extension's contributes.navigation manifest block, grouped by group.
