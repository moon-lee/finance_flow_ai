Settings

Configure Dashboard, Salary History, and Core preferences

Core
core.financialYear.current
Current financial year context. Dashboard YTD, payslip filters, and reports use this value.
Default: auto-detected
core.financialYear.start
Month and day the financial year starts. Used to compute FY labels from dates.
Default: "07-01"
core.theme
Application color theme.
Default: "dark"
core.workspace.defaultView
Extension view to activate on startup. Requires the extension to declare onStartup.
Default: "dashboard"
Dashboard
dashboard.cardOrder
Order of cards on the Dashboard. Use the Reorder Cards button below.
Default: ["net-worth","ytd-salary","last-payslip","accounts-summary"]
Salary History
salary-history.paygToleranceDollars
Tolerance in dollars for PAYG validation mismatches. Set to 0 to disable validation.
Default: 5
salary-history.sectionOrder
Order of sections in the payslip entry form. Use the button below to reorder visually.
Default: ["period","totals","earnings","deductions","super","leave","notes"]
